## What's covered

### [Session 2 — Linux Fundamentals](session2-linux/README.md)
Soft links vs hard links (inodes, creation, deletion, interview Q&A) · `adduser` vs `useradd`
· `journalctl` for system and per-service logs · the Linux command cheat sheet practised
end to end.

### [Session 3 — Shell Scripting](session3-shell-scripting/README.md)
[`system-info.sh`](session3-shell-scripting/system-info.sh) — prints the date, hostname,
username, disk usage and running processes; uses variables and `read -p`; creates a directory
with `mkdir` and files with `touch`; saves process info using `>` redirection. Full output
included.

### [Session 4 — Networking](session4-networking/README.md)
`ip`/`ifconfig` · routing · `ping` and `traceroute` · DNS with `dig`/`nslookup` · ports with
`ss`/`netstat`/`nc` · `curl` and `wget` · ARP · plus OSI model, TCP vs UDP, port numbers and
subnetting.

### [Session 5 — Git & GitHub](session5-git-github/README.md)
`git commit -a -m` vs `git commit -m` demonstrated side by side · a full cherry-pick workflow
with verification · conflict handling · a Git command cheat sheet.

### [Session 6 & 7 — Docker Fundamentals](session6-7-docker/README.md)
Six Hello World web applications, each with its own Dockerfile, built and verified:
**Nginx**, **Apache**, **React**, **Python (Flask)**, **Node.js** and **Java**.

### [Session 7 — Docker Images](session6-7-docker/multi-stage-dockerfile/README.md)
Multi-stage build running on port **8080** · measured size comparison
(**1.19 GB → 93.4 MB**, 92% smaller) · layer caching and image optimisation.

### [Session 8 — Docker Networking & Volumes](session8-docker-networking-volume/README.md)
Three containers across three networks with the backend on all of them · network isolation
demonstrated · host networking with Apache on port 80 · bind mounts updating live without a
restart · named volumes · overlay networks.
