# AWS S3 - Simple Storage Service

## 1. What is S3?
Amazon Simple Storage Service (Amazon S3) is an object storage service offering industry-leading scalability, data availability, security, and performance.

## 2. Core Concepts
- **Buckets**: Containers for objects stored in S3.
- **Objects**: Files and metadata stored within buckets.
- **Storage Classes**: Standard, Intelligent-Tiering, Standard-IA, One Zone-IA, Glacier Flexible Retrieval, Glacier Deep Archive.
- **Versioning**: Preserve, retrieve, and restore every version of every object.
- **Lifecycle Policies**: Automate object transition to cost-effective storage classes or deletion.
- **Encryption**: Server-side encryption (SSE-S3, SSE-KMS, SSE-C) and Client-side encryption.
- **Bucket Policies**: Resource-based JSON policy permissions applied at the bucket level.
