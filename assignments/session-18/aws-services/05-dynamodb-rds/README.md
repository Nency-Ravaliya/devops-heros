# AWS Database Services: DynamoDB & RDS

## 1. Amazon DynamoDB (NoSQL)
Fully managed Key-Value and Document NoSQL database designed for single-digit millisecond performance.
- **Key Concepts**: Tables, Items, Attributes, Partition Key (HASH), Sort Key (RANGE).
- **Use Cases**: Session stores, gaming leaderboards, real-time analytics, mobile backends.

## 2. Amazon RDS (Relational Database Service)
Managed relational database service supporting multiple engines.
- **Supported Engines**: PostgreSQL, MySQL, MariaDB, Oracle, SQL Server, Amazon Aurora.
- **Key Features**: Automated backups, Multi-AZ deployments for high availability, Read Replicas for scale, Storage autoscaling.
- **Use Cases**: E-commerce platforms, ERP systems, financial transaction processing.
