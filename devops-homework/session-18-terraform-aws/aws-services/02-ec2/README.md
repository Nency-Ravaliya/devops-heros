# EC2

EC2 provides virtual machines. An AMI supplies the initial OS/image and an
instance type defines compute capacity. Key pairs can authenticate SSH; Session
Manager can avoid public SSH. Security Groups are stateful traffic rules. EBS
provides persistent block volumes and snapshots. A private IP works inside
connected networks; public access also needs a public IP, a route and permitted
traffic. Instance states include pending, running, stopped and terminated.
Stopping does not remove every storage charge. EC2 fits web servers or workloads
needing operating-system control.

Reference: https://docs.aws.amazon.com/
