## Summary

These commands were used to inspect and test Docker container networking.

- `curl` was used to test HTTP/HTTPS connectivity.
- `/etc/hosts` was inspected for hostname mappings.
- `hostname` and `hostname -I` displayed container identity and IP information.
- `ip a` and `ip route` were used to inspect network interfaces and routing.
- `nslookup` verified DNS resolution.
- `ping` tested network connectivity.
- `ss` displayed listening network ports.
- `telnet` tested TCP connectivity to a specific port.
- `tracepath` examined the network path to a remote host.
- `whoami` identified the current user inside the container.
