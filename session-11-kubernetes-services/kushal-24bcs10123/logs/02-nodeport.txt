############ From the Mac (kind maps the control-plane's 30080 to localhost:30080, like minikube ip:30080) ############

$ curl -s http://localhost:30080 | grep -o '<title>.*</title>'
<title>Welcome to nginx!</title>

$ curl -sI http://localhost:30080 | head -2
HTTP/1.1 200 OK
Server: nginx/1.25.5

############ Every node answers on 30080 - even one that runs no pod of this app ############

$ docker run --rm --network kind curlimages/curl:8.5.0 -s -m 5 -o /dev/null -w "kushal-lab-control-plane (172.18.0.2):30080 -> HTTP %{http_code}\n" http://172.18.0.2:30080
kushal-lab-control-plane (172.18.0.2):30080 -> HTTP 200
