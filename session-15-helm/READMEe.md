The complete Helm rollback workflow was practiced.

helm status simple-chart

18. Important Helm Commands Practiced
Command	Purpose
helm create	Creates a new Helm chart
helm install	Installs a Helm chart
helm list	Lists installed Helm releases
helm status	Shows the status of a Helm release
helm get	Retrieves information about a Helm release
helm upgrade	Upgrades an existing Helm release
helm history	Shows the revision history of a release
helm rollback	Rolls a release back to a previous revision
helm uninstall	Removes a Helm release
helm repo add	Adds a Helm repository
helm repo update	Updates Helm repository information
helm repo list	Lists configured Helm repositories
helm search repo	Searches for charts in Helm repositories
19. Helm Chart Structure

A standard Helm chart contains the following structure:

simple-chart/
├── Chart.yaml
├── values.yaml
├── charts/
└── templates/
Chart.yaml

Chart.yaml contains information about the Helm chart such as its name and version.

values.yaml

values.yaml contains configurable values used by the templates.

charts/

The charts/ directory can contain chart dependencies.

templates/

The templates/ directory contains Kubernetes resource templates that Helm uses to generate Kubernetes manifests.
