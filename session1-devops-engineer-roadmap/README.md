# Session 1: DevOps Engineer Roadmap & Fundamentals

Welcome to the foundational session of the DevOps engineering curriculum. This session covers the core mindset, culture, tooling landscape, and end-to-end roadmap for a modern Cloud & DevOps Engineer.

---

## Key Topics Covered

1. **What is DevOps?**
   - The evolution from traditional Waterfall and Agile to DevOps culture.
   - Breaking the silos between Development (Dev) and Operations (Ops).
   - The CALMS framework (Culture, Automation, Lean, Measurement, Sharing).

2. **The Modern DevOps Roadmap:**
   - **Linux & Shell Scripting**: System navigation, permissions, process management, Bash automation.
   - **Computer Networking**: OSI model, TCP/IP, DNS, routing, load balancing, firewalls.
   - **Version Control & Collaboration**: Git branching workflows, GitHub, PRs, merge strategies.
   - **Containerization**: Docker architecture, Dockerfile optimization, multi-stage builds.
   - **Container Orchestration**: Kubernetes architecture, pods, services, ingress, storage, autoscaling.
   - **Infrastructure as Code (IaC)**: Terraform, cloud provisioning (AWS), state management.
   - **CI/CD Pipelines**: Automated build, test, and release workflows (GitHub Actions, Jenkins).
   - **DevSecOps**: Security scanning (SAST, DAST, SCA, container image scans).
   - **Observability & GitOps**: Prometheus, Grafana, ArgoCD, declarative continuous delivery.
