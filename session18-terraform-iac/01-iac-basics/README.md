# 01 - What is Infrastructure as Code?

Infrastructure as Code means defining infrastructure using code instead of manually creating every resource through a cloud console.

Traditional approach:

```text
Open AWS Console
   ↓
Click S3
   ↓
Create bucket
   ↓
Add configuration
   ↓
Repeat manually
```

IaC approach:

```text
Terraform code
     ↓
terraform plan
     ↓
terraform apply
     ↓
AWS infrastructure
```

## Why IaC?

- Repeatability
- Automation
- Version control
- Consistency
- Review through Git
- Easier disaster recovery
- Easier CI/CD integration

## Code

```hcl
resource "aws_s3_bucket" "iac_demo" {
  bucket_prefix = "session18-iac-"

  tags = {
    Name        = "Session 18 IaC Demo"
    Environment = "dev"
  }
}
```

## Run It

```bash
terraform init
terraform fmt
terraform validate
terraform plan
terraform apply
```

Enter:

```text
yes
```

Expected:

```text
Plan: 1 to add, 0 to change, 0 to destroy.

Apply complete! Resources: 1 added, 0 changed, 0 destroyed.

Outputs:

bucket_name = "session18-iac-xxxxxxxx"
```

The exact bucket name is generated by AWS/Terraform.

## Verify

```bash
terraform output bucket_name
terraform state list
```

Expected:

```text
aws_s3_bucket.iac_demo
```

## Cleanup

```bash
terraform destroy
```

Enter:

```text
yes
```
