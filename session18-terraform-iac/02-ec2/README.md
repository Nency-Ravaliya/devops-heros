# Amazon EC2

## What is EC2?
Amazon Elastic Compute Cloud (EC2) provides resizable virtual servers in the AWS Cloud.

## AMI
An Amazon Machine Image (AMI) is a template used to launch EC2 instances. It contains the operating system and required software.

## Instance Types
EC2 provides different instance types optimized for general purpose, compute, memory, storage, and accelerated workloads.

## Key Pairs
Key pairs are used to securely connect to EC2 instances. The private key is used for authentication.

## Security Groups
Security groups act as virtual firewalls that control inbound and outbound traffic for EC2 instances.

## EBS
Amazon Elastic Block Store (EBS) provides persistent block storage volumes for EC2 instances.

## Public and Private IP
A public IP allows an instance to communicate over the internet. A private IP is used for communication inside the VPC.

## EC2 Lifecycle
An EC2 instance can be launched, stopped, started, rebooted, and terminated.

## Common Uses
EC2 is commonly used for web servers, application servers, development environments, databases, and other computing workloads.
