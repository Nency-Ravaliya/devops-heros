# Amazon S3

## What is S3?
Amazon Simple Storage Service (S3) is an object storage service used to store and retrieve data.

## Bucket
A bucket is a container used to store objects in Amazon S3.

## Object
An object is a file stored in an S3 bucket. It consists of the data and associated metadata.

## Storage Classes
S3 provides different storage classes for different access patterns, including Standard, Intelligent-Tiering, Standard-IA, One Zone-IA, Glacier Instant Retrieval, Glacier Flexible Retrieval, and Glacier Deep Archive.

## Versioning
S3 Versioning keeps multiple versions of objects, helping protect against accidental deletion or overwriting.

## Lifecycle
S3 Lifecycle rules automatically transition objects between storage classes or delete objects after a specified period.

## Encryption
S3 supports encryption to protect stored data. Encryption can be managed by AWS or configured using customer-managed keys.

## Bucket Policies
Bucket policies are resource-based policies that control access to objects and actions in an S3 bucket.

## Common Uses
S3 is commonly used for backups, static website files, data storage, logs, media files, and data lakes.
