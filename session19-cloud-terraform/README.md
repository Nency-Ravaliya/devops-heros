# Session 19 Assignment

## What was the task?

**We were instructed to Build an ent-toend cloud infrastructure project using Terraform**

## What was build:

- Created an AWS VPC with public subnet 
- Configured an Internet Gateway, public route tablem and security group for HTTP?HTTPS traffic
- Created and managed AWS infrastructure using Terraform variables, resources, outputs and dependencies
- Craeted an S3 bucket and practiced Terraform state management
- Executed the Terraform workflow using terraform init, terraform plan, terraform apply and terraform destory.
