$ kubectl -n studytrack logs studytrack-broken-image-f9bc74596-q5rw6
Error from server (BadRequest): container "backend" in pod "studytrack-broken-image-f9bc74596-q5rw6" is waiting to start: image can't be pulled

ROOT CAUSE: the tag 'does-not-exist' is not in ghcr.io/kushaltalati/studytrack-backend (registry answers 'manifest unknown'), so kubelet cannot pull and keeps backing off (ErrImagePull -> ImagePullBackOff). Nothing to see in logs: the container never started.
FIX: point the Deployment at a tag that exists (the sha tag the pipeline pushed, or latest).

$ kubectl -n studytrack set image deployment/studytrack-broken-image backend=ghcr.io/kushaltalati/studytrack-backend:sha-da417a0
