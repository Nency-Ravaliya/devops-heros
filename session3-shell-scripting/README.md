## System Information Script

This project contains a Bash script that displays basic system information.

### Information Displayed

- Hostname
- Operating system
- Kernel version
- Current user
- System uptime
- Date and time
- Disk usage
- Memory usage

### Script

The `system-info.sh` script uses common Linux commands such as:

```bash
hostname
cat
grep
uname
whoami
uptime
date
