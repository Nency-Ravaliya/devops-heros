# Session 3 - Shell Scripting Assignment

## Task: System Information Script

Write a shell script that displays:
- Current date
- Hostname
- Username
- Disk usage
- Running processes

**Requirements:** use variables, `read -p` for input, `mkdir`, `touch`, `echo`, `df`, `ps`, and output redirection (`>`).

### Script

See [task.sh](task.sh).

The script:
1. Creates a `sysinfo_report/` directory and a `system_info.txt` file inside it (`mkdir`, `touch`).
2. Captures the current date, hostname and username into variables and writes them to the report file.
3. Adds logged-in user info (`who`, `w`).
4. Adds disk usage (`df -h`).
5. Dumps the running process list into `process.log` (`ps > process.log`) and drops a note in the report.
6. Prompts for name, roll number and comment via `read -p` and appends them to the report.

### Run it

```bash
bash task.sh
```
