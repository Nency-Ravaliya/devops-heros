This Bash script asks the user to enter a number. The loop keeps running because `while true` is true. The user can type `q` to quit. When `q` is entered, the script prints a message and ends the loop with `break`. The script checks whether the input contains numbers. If the input has letters or symbols, it shows an error message and asks again. The `continue` command skips back to the next question after invalid input. When the user enters a valid number, the script displays it. This example shows how loops, input checks, `break`, and `continue` work in Bash.
