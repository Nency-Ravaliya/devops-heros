Based on the class discussion, there are a few homework assignments mentioned:
Create three different containers (frontend, backend, and DB) using three different networks:
Use nginx or Alpine image for frontend and backend
Use MySQL image for DB
Create three different networks
Add the backend container to two networks
Check the connectivity between each container
Use Apache2 image with host network:
Pull the Apache2 image from Docker Hub
Create a container using host network
Access the Apache website directly on port 80
Perform the bind mount exercise:
Create a folder on your local machine
Create an index.html file with "Hello students" content
Bind mount this folder to an nginx container
Access the nginx website and verify the content
Modify the index.html file and verify that changes reflect without restarting the container
Take screenshots of the process and add them to the README file
Research and understand overlay networks:
Learn about the use cases for overlay networks
Understand how they work with multiple Docker hosts
Complete any remaining exercises from the session that weren't finished during class time.
The instructor emphasized that they will be checking repositories over the weekend to ensure students have completed their homework assignments.
