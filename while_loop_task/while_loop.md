* The Endless Loop: It's a game that keeps asking you for a number over and over again forever as it has "while True" in it.

* The Quit Button: If you type q, it gives up and stops running.

* The Bouncer: If you type letters or symbols instead of a number, it scolds you and forces you to try again.

* The Printer: If you type a number, it prints it back to you and asks for another number.
